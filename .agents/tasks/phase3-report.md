# Фаза 3: отчёт

## Что сделано

- **Сначала — красный CI на master.** cargo-deny падал на четырёх новых уязвимостях rustls 0.23.45 (RUSTSEC-2026-0346…0349); обновлено до 0.23.46 (PR #1). Фаза 3 — PR #2 поверх него, по коммиту на каждую часть.
- **Поиск в локальной сети** (UDP 47801). `macwin pair --code КОД` сам находит компьютер, который ждёт сопряжения, без ввода IP; ожидающая сторона подсказывает короткую команду (и адрес — на случай, если поиск не сработает). В `macwin run` слушающая сторона отвечает своему партнёру, а набирающая при неудаче спрашивает сеть, подключается по новому адресу и сохраняет его (если в конфиге был IP; имена хостов не трогаются). Отпечатки не транслируются в открытом виде (теги SHA-256 с nonce), а ответы — только подсказки: сопряжение по-прежнему защищено кодом, сеансы — пиннингом сертификата. Настройки `discovery`, `discovery-port`.
- **Автозапуск:** `macwin autostart on|off|status`. macOS — LaunchAgent `~/Library/LaunchAgents/io.macwin.MacWin.plist` (запускает `macwin tray`, только в графическом сеансе, без KeepAlive — выход из трея не отменяется). Windows — значение `macwin` в `HKCU\…\Run` → `macwin-tray.exe`.
- **Трей:** значок в строке меню (macOS: NSStatusItem, символы SF Symbols) и в области уведомлений (Windows: Shell_NotifyIconW, цветной кружок). Меню: состояние, «Pause/Resume sharing», «Share clipboard», сторона второго компьютера, «Pair with another computer…» (показывает код), «Enter pairing code…» (поиск + сопряжение), «Start at login», «Quit». Экстренный аккорд в трее ставит паузу вместо выхода. Вся логика — в контроллере агента (тестируется без экрана); ОС-слои тонкие и только опрашивают модель представления раз в 200 мс.
- **Точки входа:** `macwin tray`; MacWin.app без аргументов открывает трей (аргумент Finder `-psn_` игнорируется); `macwin-tray.exe` — GUI-приложение без окна консоли. Один экземпляр на пользователя: `run` и трей берут блокировку файла, второй экземпляр завершается. Лог трея: `~/Library/Logs/macwin/macwin.log` (там же его показывает `run.sh`) / `%LOCALAPPDATA%\macwin\macwin.log`, включая паники.
- **Пакеты:** `scripts/macos/dmg.sh` (MacWin.app + ссылка на «Программы»), `scripts/windows/package.sh` (zip: macwin.exe, macwin-tray.exe, install.cmd, install.ps1, uninstall.ps1, README.txt). `install.ps1`: установка для текущего пользователя в `%LOCALAPPDATA%\Programs\macwin`, PATH, автозапуск, правила брандмауэра UDP 47800–47801 для частных сетей (одно повышение прав; `-AllNetworks` — и для общедоступных), запуск трея. `uninstall.ps1` всё убирает (`-Purge` — ещё настройки и ключ). Релизная сборка без символов: macwin.exe 38 → 8 МБ.
- **CI:** новая задача `package` собирает пакеты и проверяет их: dmg монтируется, подпись приложения валидна, бинарник запускается; zip распаковывается, ставится (файлы, Run, два правила брандмауэра, `autostart status`) и удаляется без остатков. Пакеты сохраняются артефактами на 14 дней — их можно скачать для проверки на железе.
- **Фаза 4** (по плану — оценка и проект): `phase4-design.md`. Вывод: выполнимо как опциональная служба SYSTEM с агентом сеанса, который следует за входным рабочим столом; Ctrl+Alt+Del — через SendSAS из службы.

## Не проверено вручную

Трей на настоящих Mac и PC (значок, меню, окна кода и уведомления, поведение с открытым меню), разрешение Local Network на macOS 15 для широковещания, поиск в реальной сети (Wi-Fi с изоляцией клиентов, VPN), автозапуск после перезагрузки, установщик на чистой Windows от обычного пользователя (запрос UAC), предупреждения Gatekeeper и SmartScreen.

## Известные ограничения

- Поиск — только IPv4-широковещание в пределах подсети; через VPN или при изоляции клиентов Wi-Fi — сопряжение по адресу.
- Уведомления на macOS — модальные окна, их закрывают вручную; устаревшее окно с кодом не закрывается само (`abortModal` может бросать исключение Objective-C, а его раскрутка через кадры Rust — неопределённое поведение).
- Пакеты не подписаны для распространения и не нотаризованы.
- Брандмауэр Windows по умолчанию открыт только для частных сетей; сеть, помеченная «Общедоступной», блокирует macwin до `-AllNetworks` или смены профиля.
- Выход из трея и выход из системы закрывают сеанс штатно; на macOS процесс завершается сразу после остановки контроллера.
